# Tropalha

Party game 3D de física, cooperação e caos para até 8 amigos.
Carreguem vasos frágeis, corram de kart, sobrevivam à lava e atrapalhem os amigos com bazuca e casca de banana.

## Baixar
Vá em **[Releases](https://github.com/sigajunto/tropalha/releases)**, baixe o `.zip`, extraia a pasta inteira e abra `Tropalha.exe`.

- Windows 10/11 64-bit, placa de vídeo com Vulkan.
- O Windows pode mostrar o aviso do SmartScreen (o jogo ainda não tem assinatura digital):
  clique em **Mais informações → Executar assim mesmo**.
- Versão **alpha**: pode ter bugs.

## Modos
Solo (com bots), sala **online por código** de 6 letras, ou rede local por IP.
